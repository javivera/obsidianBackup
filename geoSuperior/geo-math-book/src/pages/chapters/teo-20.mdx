# Tensores covariantes

### Un poco de algebra multilineal

<BookBlock kind="definition">
Sean <Math tex={"V_1,V_2,\\ldots,V_k"} /> y <Math tex={"W"} /> espacios vectoriales. Una funcion
<Math display tex={"F:V_1\\times\\cdots\\times V_k\\to W"} />
se dice multilineal si esta es lineal en cada variable, es decir, <Math tex={"\\lambda\\in\\mathbb R"} />,
<Math display tex={"F(v_1,\\ldots,\\lambda v_i+\\tilde v_i,\\ldots,v_k) = \\lambda F(v_1,\\ldots,v_i,\\ldots,v_k)+F(v_1,\\ldots,\\tilde v_i,\\ldots,v_k),"} />
<Math tex={"i=1,\\ldots,k"} />.
</BookBlock>

<span id="2f1d75"></span>

<BookBlock kind="definition" title="Conjunto de funciones multilineales">
Se suele denotar por <Math tex={"L(V_1,\\ldots,V_k;W)"} /> el conjunto de todas las funciones multilineales de <Math tex={"V_1\\times\\cdots\\times V_k"} /> en <Math tex={"W"} />, el cual resulta ser un espacio vectorial real bajo la suma y producto escalar natural. Si <Math tex={"\\lambda\\in\\mathbb R"} />:
<Math display tex={"(F+G)(v_1,\\ldots,v_k):=F(v_1,\\ldots,v_k)+G(v_1,\\ldots,v_k),"} /><Math display tex={"(\\lambda F)(v_1,\\ldots,v_k):=\\lambda F(v_1,\\ldots,v_k)."} />
</BookBlock>

<BookBlock kind="example">
<Math display tex={"\\det:\\underbrace{\\mathbb R^n\\times\\cdots\\times\\mathbb R^n}_{n\\text{-veces}}\\to\\mathbb R"} />
<Math display tex={"\\det(v_1,\\ldots,v_n)=\\det(v_1|\\cdots|v_n)."} />
</BookBlock>

<BookBlock kind="example">
<Math display tex={"\\langle\\ ,\\ \\rangle:\\mathbb R^n\\times\\mathbb R^n\\to\\mathbb R"} />
<Math display tex={"((x_1,\\ldots,x_n),(y_1,\\ldots,y_n))\\mapsto \\langle v_1,v_2\\rangle=\\sum_{k=1}^n x_k y_k."} />
Producto interno usual de <Math tex={"\\mathbb R^n"} />.
</BookBlock>

<BookBlock kind="example">
<Math display tex={"\\times:\\mathbb R^3\\times\\mathbb R^3\\to\\mathbb R^3"} />
<Math display tex={"((x_1,x_2,x_3),(y_1,y_2,y_3)) \\mapsto \\det\\begin{pmatrix} e_1&e_2&e_3\\\\ x_1&x_2&x_3\\\\ y_1&y_2&y_3 \\end{pmatrix},"} />
el producto cruz en <Math tex={"\\mathbb R^3"} />.
</BookBlock>

<BookBlock kind="definition" title="Producto tensorial">
Sean <Math tex={"V_1,\\ldots,V_k,W_1,\\ldots,W_l"} /> espacios vectoriales reales y sean
<Math display tex={"F\\in L(V_1,\\ldots,V_k;\\mathbb R),\\qquad G\\in L(W_1,\\ldots,W_l;\\mathbb R),"} />
y considerar la funcion
<Math display tex={"F\\otimes G:V_1\\times\\cdots\\times V_k\\times W_1\\times\\cdots\\times W_l\\to\\mathbb R"} />
<Math display tex={"(v_1,\\ldots,v_k,w_1,\\ldots,w_l)\\mapsto F(v_1,\\ldots,v_k)G(w_1,\\ldots,w_l)."} />
Es facil ver que <Math tex={"F\\otimes G"} /> es multilineal, asi que
<Math display tex={"F\\otimes G\\in L(V_1,\\ldots,V_k,W_1,\\ldots,W_l;\\mathbb R)"} />
y se llama el producto tensorial de <Math tex={"F"} /> y <Math tex={"G"} />.
</BookBlock>

<span id="db8d92"></span>

<BookBlock kind="exercise">
Probar que el producto tensorial es bilineal y asociativo:
<Math display tex={"(F+\\lambda H)\\otimes G=F\\otimes G+\\lambda(H\\otimes G),"} />
<Math display tex={"F\\otimes(G+\\beta K)=F\\otimes G+\\beta(F\\otimes K),"} />
<Math display tex={"(F\\otimes G)\\otimes K=F\\otimes(G\\otimes K)."} />
</BookBlock>

<BookBlock kind="proposition" title="Ejercicio">
Sean <Math tex={"V_1,\\ldots,V_k"} /> espacios vectoriales reales de dimension finita <Math tex={"n_1,\\ldots,n_k"} /> respectivamente, y sea <Math tex={"\\{e^j_1,\\ldots,e^j_{n_j}\\}"} /> una base de <Math tex={"V_j"} />, <Math tex={"j=1,\\ldots,k"} />, y sean <Math tex={"\\{\\varepsilon^j_1,\\ldots,\\varepsilon^j_{n_j}\\}"} /> la respectiva base dual de <Math tex={"V_j^*"} />.

Entonces
<Math display tex={"B=\\left\\{\\varepsilon^1_{i_1}\\otimes\\cdots\\otimes\\varepsilon^k_{i_k}:1\\le i_j\\le n_j,\\ 1\\le j\\le k\\right\\}"} />
es una base para <Math tex={"L(V_1,\\ldots,V_k;\\mathbb R)"} />, el cual es un espacio vectorial real de dimension <Math tex={"n_1n_2\\cdots n_k"} />.
<Proof title="hecha por chat">
1. Para cada multiíndice <Math tex={"(i_1,\\ldots,i_k)"} />, definimos <Math display tex={"E_{i_1,\\ldots,i_k}:=\\varepsilon^1_{i_1}\\otimes\\cdots\\otimes\\varepsilon^k_{i_k}."} />  
2. Por definición del producto tensorial, para <Math tex={"v_j\\in V_j"} />, se tiene <Math display tex={"E_{i_1,\\ldots,i_k}(v_1,\\ldots,v_k)=\\varepsilon^1_{i_1}(v_1)\\cdots\\varepsilon^k_{i_k}(v_k)."} />  
3. En particular, si evaluamos en vectores de las bases, obtenemos <Math display tex={"E_{i_1,\\ldots,i_k}(e^1_{a_1},\\ldots,e^k_{a_k})=\\varepsilon^1_{i_1}(e^1_{a_1})\\cdots\\varepsilon^k_{i_k}(e^k_{a_k})."} />  
4. Como <Math tex={"\\{\\varepsilon^j_1,\\ldots,\\varepsilon^j_{n_j}\\}"} /> es la base dual de <Math tex={"\\{e^j_1,\\ldots,e^j_{n_j}\\}"} />, vale <Math display tex={"\\varepsilon^j_{i_j}(e^j_{a_j})=\\delta_{i_ja_j}."} />  
5. Luego <Math display tex={"E_{i_1,\\ldots,i_k}(e^1_{a_1},\\ldots,e^k_{a_k})=\\delta_{i_1a_1}\\cdots\\delta_{i_ka_k}."} />  
6. Por lo tanto, este valor es <Math tex={"1"} /> si <Math tex={"(i_1,\\ldots,i_k)=(a_1,\\ldots,a_k)"} />, y es <Math tex={"0"} /> en caso contrario.  
7. Probemos primero que <Math tex={"B"} /> es linealmente independiente. Supongamos que <Math display tex={"\\sum_{i_1=1}^{n_1}\\cdots\\sum_{i_k=1}^{n_k}c_{i_1,\\ldots,i_k}E_{i_1,\\ldots,i_k}=0."} />  
8. Evaluamos ambos lados en <Math tex={"(e^1_{a_1},\\ldots,e^k_{a_k})"} />. Entonces <Math display tex={"0=\\sum_{i_1=1}^{n_1}\\cdots\\sum_{i_k=1}^{n_k}c_{i_1,\\ldots,i_k}E_{i_1,\\ldots,i_k}(e^1_{a_1},\\ldots,e^k_{a_k})."} />  
9. Usando el cálculo anterior, <Math display tex={"0=\\sum_{i_1=1}^{n_1}\\cdots\\sum_{i_k=1}^{n_k}c_{i_1,\\ldots,i_k}\\delta_{i_1a_1}\\cdots\\delta_{i_ka_k}."} />  
10. Todos los términos se anulan salvo el término con <Math tex={"(i_1,\\ldots,i_k)=(a_1,\\ldots,a_k)"} />, por lo tanto <Math display tex={"c_{a_1,\\ldots,a_k}=0."} />  
11. Como <Math tex={"(a_1,\\ldots,a_k)"} /> era arbitrario, todos los coeficientes son cero. Luego <Math tex={"B"} /> es linealmente independiente.  
12. Probemos ahora que <Math tex={"B"} /> genera <Math tex={"L(V_1,\\ldots,V_k;\\mathbb R)"} />. Sea <Math tex={"F\\in L(V_1,\\ldots,V_k;\\mathbb R)"} />. Queremos probar que <Math display tex={"F=\\sum_{i_1=1}^{n_1}\\cdots\\sum_{i_k=1}^{n_k}F(e^1_{i_1},\\ldots,e^k_{i_k})E_{i_1,\\ldots,i_k}."} />  
13. Sean <Math tex={"v_j\\in V_j"} /> arbitrarios. Como <Math tex={"\\{e^j_1,\\ldots,e^j_{n_j}\\}"} /> es base de <Math tex={"V_j"} />, existen escalares <Math tex={"a^j_{i_j}"} /> tales que <Math display tex={"v_j=\\sum_{i_j=1}^{n_j}a^j_{i_j}e^j_{i_j}."} />  
14. Como <Math tex={"\\{\\varepsilon^j_1,\\ldots,\\varepsilon^j_{n_j}\\}"} /> es la base dual, los coeficientes están dados por <Math display tex={"a^j_{i_j}=\\varepsilon^j_{i_j}(v_j)."} />  
15. Entonces, por multilinealidad de <Math tex={"F"} />, <Math display tex={"F(v_1,\\ldots,v_k)=F\\left(\\sum_{i_1=1}^{n_1}a^1_{i_1}e^1_{i_1},\\ldots,\\sum_{i_k=1}^{n_k}a^k_{i_k}e^k_{i_k}\\right)."} />  
16. Expandiendo en cada variable, obtenemos <Math display tex={"F(v_1,\\ldots,v_k)=\\sum_{i_1=1}^{n_1}\\cdots\\sum_{i_k=1}^{n_k}a^1_{i_1}\\cdots a^k_{i_k}F(e^1_{i_1},\\ldots,e^k_{i_k})."} />  
17. Sustituyendo <Math tex={"a^j_{i_j}=\\varepsilon^j_{i_j}(v_j)"} />, queda <Math display tex={"F(v_1,\\ldots,v_k)=\\sum_{i_1=1}^{n_1}\\cdots\\sum_{i_k=1}^{n_k}\\varepsilon^1_{i_1}(v_1)\\cdots\\varepsilon^k_{i_k}(v_k)F(e^1_{i_1},\\ldots,e^k_{i_k})."} />  
18. Por definición de <Math tex={"E_{i_1,\\ldots,i_k}"} />, esto es <Math display tex={"F(v_1,\\ldots,v_k)=\\sum_{i_1=1}^{n_1}\\cdots\\sum_{i_k=1}^{n_k}F(e^1_{i_1},\\ldots,e^k_{i_k})E_{i_1,\\ldots,i_k}(v_1,\\ldots,v_k)."} />  
19. Como esto vale para todo <Math tex={"(v_1,\\ldots,v_k)"} />, concluimos que <Math display tex={"F=\\sum_{i_1=1}^{n_1}\\cdots\\sum_{i_k=1}^{n_k}F(e^1_{i_1},\\ldots,e^k_{i_k})E_{i_1,\\ldots,i_k}."} />  
20. Luego <Math tex={"B"} /> genera <Math tex={"L(V_1,\\ldots,V_k;\\mathbb R)"} />.  
21. Como <Math tex={"B"} /> es linealmente independiente y genera <Math tex={"L(V_1,\\ldots,V_k;\\mathbb R)"} />, <Math tex={"B"} /> es una base.  
22. Finalmente, para elegir un elemento de <Math tex={"B"} />, debemos elegir un índice <Math tex={"i_j"} /> entre <Math tex={"1"} /> y <Math tex={"n_j"} /> para cada <Math tex={"j=1,\\ldots,k"} />. Por lo tanto <Math tex={"B"} /> tiene <Math tex={"n_1n_2\\cdots n_k"} /> elementos, y entonces <Math display tex={"\\dim L(V_1,\\ldots,V_k;\\mathbb R)=n_1n_2\\cdots n_k."} />
</Proof>
</BookBlock>

<BookBlock kind="definition">
Sean <Math tex={"V_1,\\ldots,V_k"} /> espacios vectoriales y <Math tex={"V_1^*,\\ldots,V_k^*"} /> sus respectivos espacios duales. Se denota por
<Math display tex={"V_1^*\\otimes\\cdots\\otimes V_k^*"} />
al subespacio de <Math tex={"L(V_1,\\ldots,V_k;\\mathbb R)"} /> generado por
<Math display tex={"\\{\\alpha_1\\otimes\\cdots\\otimes\\alpha_k:\\alpha_i\\in V_i^*\\}."} />
Por la prop. anterior:
<Math display tex={"L(V_1,\\ldots,V_k;\\mathbb R)=V_1^*\\otimes\\cdots\\otimes V_k^*."} />
</BookBlock>

<BookBlock kind="proposition" title="Propiedad caracteristica del producto tensorial">
Sean <Math tex={"V_1,\\ldots,V_k"} /> espacios vectoriales reales de dimension finita y sea <Math tex={"W"} /> un espacio vectorial real (no necesariamente de dimension finita). Sea
<Math display tex={"A:V_1^*\\times\\cdots\\times V_k^*\\to W"} />
en <Math tex={"L(V_1^*,\\ldots,V_k^*;W)"} />.

Entonces existe una unica transformacion lineal
<Math display tex={"\\hat A:V_1^*\\otimes\\cdots\\otimes V_k^*\\to W"} />
tal que <Math tex={"A=\\hat A\\circ\\pi"} />, con
<Math display tex={"\\pi:V_1^*\\times\\cdots\\times V_k^*\\to V_1^*\\otimes\\cdots\\otimes V_k^*,"} />
<Math display tex={"\\pi(\\alpha_1,\\ldots,\\alpha_k)=\\alpha_1\\otimes\\cdots\\otimes\\alpha_k."} />
<Proof title="Demostracion">
1. Fijar base <Math tex={"\\{\\varepsilon^i_1,\\ldots,\\varepsilon^i_{n_i}\\}"} /> base dual de <Math tex={"V_i^*"} />.
2. La multilinealidad de <Math tex={"A"} /> nos dice que <Math tex={"A"} /> va estar determinada por lo que haga en la <Math tex={"k"} />-upla <Math display tex={"(\\varepsilon^1_{i_1},\\ldots,\\varepsilon^k_{i_k})."} />
3. Llamemos <Math display tex={"w_{i_1,\\ldots,i_k}=A(\\varepsilon^1_{i_1},\\ldots,\\varepsilon^k_{i_k})."} />
4. Por la proposicion anterior, <Math tex={"\\varepsilon^1_{i_1}\\otimes\\cdots\\otimes\\varepsilon^k_{i_k}"} /> es base de <Math tex={"V_1^*\\otimes\\cdots\\otimes V_k^*"} />, entonces definimos <Math tex={"\\hat A"} /> sobre los elementos de la base como <Math display tex={"\\hat A(\\varepsilon^1_{i_1}\\otimes\\cdots\\otimes\\varepsilon^k_{i_k})=w_{i_1,\\ldots,i_k}."} />
5. Y <Math tex={"\\hat A"} /> es la unica que cumple esta condicion, pues cualquier otra, digamos <Math tex={"\\tilde A"} />, al cumplir <Math display tex={"\\tilde A\\circ\\pi=A,"} />va a implicar que <Math display tex={"\\tilde A\\circ\\pi(\\varepsilon^1_{i_1},\\ldots,\\varepsilon^k_{i_k})=w_{i_1,\\ldots,i_k},"} />
6. Es decir <Math display tex={"\\tilde A(\\varepsilon^1_{i_1}\\otimes\\cdots\\otimes\\varepsilon^k_{i_k})=w_{i_1,\\ldots,i_k}."} />
</Proof>
</BookBlock>

## Tensores covariantes

<BookBlock kind="definition">
<Fragment slot="title"><Math tex={"k"} />-tensores covariante</Fragment>
Sea <Math tex={"V^*"} /> un espacio vectorial real de dimension finita y sea <Math tex={"k\\in\\mathbb N"} />. Un <Math tex={"k"} />-tensor covariante sobre <Math tex={"V"} /> es un elemento de <Math display tex={"\\underbrace{V^*\\otimes\\cdots\\otimes V^*}_{k\\text{-veces}},"} />lo cual es lo mismo a tener una funcion multilineal real valuada <Math display tex={"\\alpha:\\underbrace{V\\times\\cdots\\times V}_{k\\text{-veces}}\\to\\mathbb R."} />
El numero <Math tex={"k"} /> se llama rango del tensor.
Por convencion, un <Math tex={"0"} />-tensor es un numero real.
Se denota al conjunto del los <Math tex={"k"} /> tensores por <Math tex={"T^k(V^*):=V^*\\otimes\\cdots\\otimes V^*"} />, Entonces <Math display tex={"T^1(V^*)=V^*,\\qquad T^0(V^*)=\\mathbb R."} />
</BookBlock>

<BookBlock kind="definition" title="Tensores alternantes">
Sea <Math tex={"\\alpha:V\\times\\cdots\\times V\\to\\mathbb R"} /> un <Math tex={"k"} />-tensor covariante. Se dice que <Math tex={"\\alpha"} /> es alternante, si para todo <Math tex={"\\sigma\\in S_k"} />, una permutacion de <Math tex={"k"} /> elementos, se cumple <Math display tex={"\\alpha(v_{\\sigma(1)},\\ldots,v_{\\sigma(k)})=\\operatorname{sg}(\\sigma)\\alpha(v_1,\\ldots,v_k)"} />para todo <Math tex={"v_1,\\ldots,v_k\\in V"} />.
Se denota por <Math tex={"\\Lambda^k(V^*)"} /> el subconjunto de <Math tex={"T^k(V^*)"} /> formado solo por los que son alternantes, el cual es naturalmente un subespacio vectorial.
</BookBlock>

<BookBlock kind="exercise">
Mostrar que <Math tex={"\\alpha\\in\\Lambda^k(V^*)"} /> sii
<Math display tex={"\\alpha(v_1,\\ldots,v_i,\\ldots,v_j,\\ldots,v_k)=-\\alpha(v_1,\\ldots,v_j,\\ldots,v_i,\\ldots,v_k)"} />
para todo <Math tex={"i,j"} /> con <Math tex={"1\\le i<j\\le k"} />.
<Proof title="Demostracion">
1. Supongamos primero que <Math tex={"\\alpha\\in\\Lambda^k(V^*)"} />.  
2. Por definición, para toda permutación <Math tex={"\\sigma\\in S_k"} /> se cumple <Math display tex={"\\alpha(v_{\\sigma(1)},\\dots,v_{\\sigma(k)})=\\operatorname{sg}(\\sigma)\\alpha(v_1,\\dots,v_k)."} />  
3. Fijemos <Math tex={"i<j"} /> y sea <Math tex={"\\tau\\in S_k"} /> la transposición que intercambia <Math tex={"i"} /> y <Math tex={"j"} />, dejando fijos los demás índices.  
4. Entonces <Math tex={"\\operatorname{sg}(\\tau)=-1"} />.  
5. Aplicando la definición de tensor alternante a la transposición <Math tex={"\\tau"} />, obtenemos <Math display tex={"\\alpha(v_{\\tau(1)},\\dots,v_{\\tau(k)})=-\\alpha(v_1,\\dots,v_k)."} />  
6. Pero <Math tex={"(v_{\\tau(1)},\\dots,v_{\\tau(k)})"} /> es la lista <Math tex={"(v_1,\\dots,v_j,\\dots,v_i,\\dots,v_k)"} />, porque <Math tex={"\\tau"} /> intercambia solamente las posiciones <Math tex={"i"} /> y <Math tex={"j"} />.  
7. Por lo tanto, <Math display tex={"\\alpha(v_1,\\dots,v_j,\\dots,v_i,\\dots,v_k)=-\\alpha(v_1,\\dots,v_i,\\dots,v_j,\\dots,v_k)."} />  
8. Equivalentemente, <Math display tex={"\\alpha(v_1,\\dots,v_i,\\dots,v_j,\\dots,v_k)=-\\alpha(v_1,\\dots,v_j,\\dots,v_i,\\dots,v_k)."} />  
9. Recíprocamente, supongamos que para todo <Math tex={"i<j"} /> se cumple <Math display tex={"\\alpha(v_1,\\dots,v_i,\\dots,v_j,\\dots,v_k)=-\\alpha(v_1,\\dots,v_j,\\dots,v_i,\\dots,v_k)."} />  
10. Queremos probar que <Math tex={"\\alpha\\in\\Lambda^k(V^*)"} />. Es decir, queremos probar que para toda permutación <Math tex={"\\sigma\\in S_k"} /> se cumple <Math display tex={"\\alpha(v_{\\sigma(1)},\\dots,v_{\\sigma(k)})=\\operatorname{sg}(\\sigma)\\alpha(v_1,\\dots,v_k)."} />  
11. Sea entonces <Math tex={"\\sigma\\in S_k"} />. Sabemos que toda permutación puede escribirse como producto de transposiciones, es decir, existen transposiciones <Math tex={"\\tau_1,\\dots,\\tau_m"} /> tales que <Math display tex={"\\sigma=\\tau_m\\circ\\cdots\\circ\\tau_1."} />  
12. Cada transposición intercambia dos entradas. Por hipótesis, cada vez que intercambiamos dos entradas, el valor de <Math tex={"\\alpha"} /> cambia de signo.  
13. Aplicando sucesivamente esta propiedad a las transposiciones <Math tex={"\\tau_1,\\dots,\\tau_m"} />, obtenemos <Math display tex={"\\alpha(v_{\\sigma(1)},\\dots,v_{\\sigma(k)})=(-1)^m\\alpha(v_1,\\dots,v_k)."} />  
14. Por definición del signo de una permutación escrita como producto de transposiciones, se tiene <Math display tex={"\\operatorname{sg}(\\sigma)=(-1)^m."} />  
15. Luego <Math display tex={"\\alpha(v_{\\sigma(1)},\\dots,v_{\\sigma(k)})=\\operatorname{sg}(\\sigma)\\alpha(v_1,\\dots,v_k)."} />  
16. Como esto vale para toda <Math tex={"\\sigma\\in S_k"} />, se sigue que <Math tex={"\\alpha"} /> es alternante.  
17. Por lo tanto, <Math tex={"\\alpha\\in\\Lambda^k(V^*)"} />.
</Proof>
</BookBlock>

<BookBlock kind="example">
<Fragment slot="title">Algunos <Math tex={"k"} />-tensores alternantes</Fragment>
- Cualquier <Math tex={"\\alpha\\in V^*=T^1(V^*)"} /> es alternante.
- Tambien <Math display tex={"\\det:\\underbrace{\\mathbb R^n\\times\\cdots\\times\\mathbb R^n}_{n\\text{-veces}}\\to\\mathbb R"} />esta en <Math tex={"\\Lambda^n((\\mathbb R^n)^*)"} />.
</BookBlock>

<BookBlock kind="definition" title="Alternador">
Dado <Math tex={"\\theta\\in T^k(V^*)"} />, se define la parte antisimetrica de <Math tex={"\\theta"} />, denotada por <Math tex={"\\operatorname{Alt}(\\theta)"} />, como el <Math tex={"k"} />-tensor
<Math display tex={"\\operatorname{Alt}(\\theta)(v_1,\\ldots,v_k)=\\frac1{k!}\\sum_{\\sigma\\in S_k}(\\operatorname{sign}\\sigma)\\theta(v_{\\sigma(1)},\\ldots,v_{\\sigma(k)})."} />
</BookBlock>

<BookBlock kind="proposition" title="Ejercicio">
- Para todo <Math tex={"\\theta\\in T^k(V^*)"} />, se tiene <Math tex={"\\operatorname{Alt}(\\theta)\\in\\Lambda^k(V^*)"} />, lo cual define una transformacion lineal
<Math display tex={"\\operatorname{Alt}:T^k(V^*)\\to\\Lambda^k(V^*)."} />
- Si <Math tex={"\\theta\\in\\Lambda^k(V^*)"} />, entonces <Math tex={"\\operatorname{Alt}(\\theta)=\\theta"} />.
<Proof title="Demostracion">
- <Math tex={"\\operatorname{Alt}(\\theta)\\in\\Lambda^k(V^*)"} />
1. Recordemos que, para <Math tex={"\\theta\\in T^k(V^*)"} />, se define <Math display tex={"\\operatorname{Alt}(\\theta)(v_1,\\dots,v_k):=\\frac{1}{k!}\\sum_{\\sigma\\in S_k}\\operatorname{sg}(\\sigma)\\theta(v_{\\sigma(1)},\\dots,v_{\\sigma(k)})."} />  
2. Primero probamos que <Math tex={"\\operatorname{Alt}(\\theta)"} /> es multilineal. Para cada <Math tex={"\\sigma\\in S_k"} />, la aplicación <Math display tex={"(v_1,\\dots,v_k)\\mapsto \\theta(v_{\\sigma(1)},\\dots,v_{\\sigma(k)})"} /> es multilineal, porque <Math tex={"\\theta"} /> es multilineal.  
3. Como <Math tex={"\\operatorname{Alt}(\\theta)"} /> es una combinación lineal finita de aplicaciones multilineales, se sigue que <Math tex={"\\operatorname{Alt}(\\theta)"} /> es multilineal.  
4. Ahora probamos que <Math tex={"\\operatorname{Alt}(\\theta)"} /> es alternante. Sea <Math tex={"\\tau\\in S_k"} />. Queremos probar que <Math display tex={"\\operatorname{Alt}(\\theta)(v_{\\tau(1)},\\dots,v_{\\tau(k)})=\\operatorname{sg}(\\tau)\\operatorname{Alt}(\\theta)(v_1,\\dots,v_k)."} />  
5. Por definición de <Math tex={"\\operatorname{Alt}"} />, tenemos <Math display tex={"\\operatorname{Alt}(\\theta)(v_{\\tau(1)},\\dots,v_{\\tau(k)})=\\frac{1}{k!}\\sum_{\\sigma\\in S_k}\\operatorname{sg}(\\sigma)\\theta(v_{\\tau(\\sigma(1))},\\dots,v_{\\tau(\\sigma(k))})."} />  
6. Como <Math tex={"v_{\\tau(\\sigma(r))}=v_{(\\tau\\circ\\sigma)(r)}"} />, podemos escribir <Math display tex={"\\operatorname{Alt}(\\theta)(v_{\\tau(1)},\\dots,v_{\\tau(k)})=\\frac{1}{k!}\\sum_{\\sigma\\in S_k}\\operatorname{sg}(\\sigma)\\theta(v_{(\\tau\\circ\\sigma)(1)},\\dots,v_{(\\tau\\circ\\sigma)(k)})."} />  
7. Hacemos el cambio de variable <Math tex={"\\rho=\\tau\\circ\\sigma"} />. Cuando <Math tex={"\\sigma"} /> recorre <Math tex={"S_k"} />, también <Math tex={"\\rho"} /> recorre <Math tex={"S_k"} />. Además, <Math tex={"\\sigma=\\tau^{-1}\\circ\\rho"} />.  
8. Entonces <Math display tex={"\\operatorname{sg}(\\sigma)=\\operatorname{sg}(\\tau^{-1}\\circ\\rho)=\\operatorname{sg}(\\tau^{-1})\\operatorname{sg}(\\rho)=\\operatorname{sg}(\\tau)\\operatorname{sg}(\\rho)."} />  
9. Sustituyendo en la suma, obtenemos <Math display tex={"\\begin{aligned}\\operatorname{Alt}(\\theta)(v_{\\tau(1)},\\dots,v_{\\tau(k)})&=\\frac{1}{k!}\\sum_{\\rho\\in S_k}\\operatorname{sg}(\\tau)\\operatorname{sg}(\\rho)\\theta(v_{\\rho(1)},\\dots,v_{\\rho(k)})\\\\&=\\operatorname{sg}(\\tau)\\frac{1}{k!}\\sum_{\\rho\\in S_k}\\operatorname{sg}(\\rho)\\theta(v_{\\rho(1)},\\dots,v_{\\rho(k)})\\\\&=\\operatorname{sg}(\\tau)\\operatorname{Alt}(\\theta)(v_1,\\dots,v_k).\\end{aligned}"} />  
10. Por lo tanto, <Math tex={"\\operatorname{Alt}(\\theta)"} /> es alternante. Como además es multilineal, se tiene <Math tex={"\\operatorname{Alt}(\\theta)\\in\\Lambda^k(V^*)"} />. 
- **Linealidad**
1. Ahora probamos que <Math tex={"\\operatorname{Alt}:T^k(V^*)\\to\\Lambda^k(V^*)"} /> es lineal. Sean <Math tex={"\\theta,\\eta\\in T^k(V^*)"} /> y <Math tex={"a,b\\in\\mathbb R"} />.  
2. Entonces <Math display tex={"\\begin{aligned}\\operatorname{Alt}(a\\theta+b\\eta)(v_1,\\dots,v_k)&=\\frac{1}{k!}\\sum_{\\sigma\\in S_k}\\operatorname{sg}(\\sigma)(a\\theta+b\\eta)(v_{\\sigma(1)},\\dots,v_{\\sigma(k)})\\\\&=a\\frac{1}{k!}\\sum_{\\sigma\\in S_k}\\operatorname{sg}(\\sigma)\\theta(v_{\\sigma(1)},\\dots,v_{\\sigma(k)})\\\\&\\quad+b\\frac{1}{k!}\\sum_{\\sigma\\in S_k}\\operatorname{sg}(\\sigma)\\eta(v_{\\sigma(1)},\\dots,v_{\\sigma(k)})\\\\&=a\\operatorname{Alt}(\\theta)(v_1,\\dots,v_k)+b\\operatorname{Alt}(\\eta)(v_1,\\dots,v_k).\\end{aligned}"} />  
3. Por lo tanto, <Math display tex={"\\operatorname{Alt}(a\\theta+b\\eta)=a\\operatorname{Alt}(\\theta)+b\\operatorname{Alt}(\\eta)."} /> Así, <Math tex={"\\operatorname{Alt}"} /> es lineal.
- <Math tex={"\\operatorname{Alt}(\\theta)=\\theta"} />
1. Finalmente, supongamos que <Math tex={"\\theta\\in\\Lambda^k(V^*)"} />. Entonces, para toda <Math tex={"\\sigma\\in S_k"} />, se cumple <Math display tex={"\\theta(v_{\\sigma(1)},\\dots,v_{\\sigma(k)})=\\operatorname{sg}(\\sigma)\\theta(v_1,\\dots,v_k)."} />  
2. Por la definición de <Math tex={"\\operatorname{Alt}"} />, <Math display tex={"\\begin{aligned}\\operatorname{Alt}(\\theta)(v_1,\\dots,v_k)&=\\frac{1}{k!}\\sum_{\\sigma\\in S_k}\\operatorname{sg}(\\sigma)\\theta(v_{\\sigma(1)},\\dots,v_{\\sigma(k)})\\\\&=\\frac{1}{k!}\\sum_{\\sigma\\in S_k}\\operatorname{sg}(\\sigma)\\operatorname{sg}(\\sigma)\\theta(v_1,\\dots,v_k).\\end{aligned}"} />  
3. Como <Math tex={"\\operatorname{sg}(\\sigma)^2=1"} />, resulta <Math display tex={"\\begin{aligned}\\operatorname{Alt}(\\theta)(v_1,\\dots,v_k)&=\\frac{1}{k!}\\sum_{\\sigma\\in S_k}\\theta(v_1,\\dots,v_k)\\\\&=\\frac{1}{k!}k!\\theta(v_1,\\dots,v_k)\\\\&=\\theta(v_1,\\dots,v_k).\\end{aligned}"} />  
4. Como esto vale para todo <Math tex={"v_1,\\dots,v_k\\in V"} />, concluimos que <Math display tex={"\\operatorname{Alt}(\\theta)=\\theta."} />
</Proof>
</BookBlock>

<BookBlock kind="theorem">
Sea <Math tex={"\\{e_1,\\ldots,e_n\\}"} /> base de <Math tex={"V"} /> y <Math tex={"\\{e^*_1,\\ldots,e^*_n\\}"} /> la respectiva base dual de <Math tex={"V^*"} />. Si <Math tex={"k\\le n"} />, entonces

es una base de <Math tex={"\\Lambda^k(V^*)"} /> y
<Math display tex={"\\dim\\Lambda^k(V^*)=\\binom nk."} />

Si <Math tex={"k>n"} />, entonces <Math tex={"\\Lambda^k(V^*)=\\{0\\}"} />.
<Proof title="Demostracion">
Veamos primero que <Math tex={"\\mathcal B"} /> es un conjunto L.I. Si
<Math display tex={"0=\\sum_{1\\le i_1<\\cdots<i_k\\le n}c_{i_1,\\ldots,i_k}e^*_{i_1}\\wedge\\cdots\\wedge e^*_{i_k},"} />
evaluamos en la <Math tex={"k"} />-upla <Math tex={"(e_{j_1},\\ldots,e_{j_k})"} />, con <Math tex={"1\\le j_1<\\cdots<j_k\\le n"} />.

Como
<Math display tex={"e^*_{i_1}\\wedge\\cdots\\wedge e^*_{i_k}(e_{j_1},\\ldots,e_{j_k}) = \\begin{cases} 1 & \\text{si }(i_1,\\ldots,i_k)=(j_1,\\ldots,j_k),\\\\ 0 & \\text{en otro caso}, \\end{cases}"} />
resulta <Math tex={"c_{i_1,\\ldots,i_k}=0"} /> para todo <Math tex={"1\\le i_1<\\cdots<i_k\\le n"} />.

Veamos que genera. Sea <Math tex={"\\theta\\in\\Lambda^k(V^*)"} /> y entonces, como <Math tex={"\\theta\\in T^k(V^*)"} />,
<Math display tex={"\\theta=\\sum a_{i_1,\\ldots,i_k}e^*_{i_1}\\otimes\\cdots\\otimes e^*_{i_k}."} />
Entonces, como <Math tex={"\\theta\\in\\Lambda^k(V^*)"} />,
<Math display tex={"\\theta=\\operatorname{Alt}\\theta= \\sum a_{i_1,\\ldots,i_k}\\operatorname{Alt}(e^*_{i_1}\\otimes\\cdots\\otimes e^*_{i_k})."} />
Luego se reordena cada termino, y si hay al menos dos indices iguales el termino es cero; si no,
<Math display tex={"\\operatorname{Alt}(e^*_{i_1}\\otimes\\cdots\\otimes e^*_{i_k})=\\text{multiplo de }e^*_{i_{\\sigma(1)}}\\wedge\\cdots\\wedge e^*_{i_{\\sigma(k)}}"} />

</Proof>

<BookBlock kind="definition" title="Algebra exterior">
Se define <Math tex={"\\Lambda^0(V^*)=\\mathbb R"} />.
Se define <Math display tex={"\\Lambda(V^*):=\\Lambda^0(V^*)\\oplus\\Lambda^1(V^*)\\oplus\\cdots\\oplus\\Lambda^n(V^*)"} />y se extiende el producto cuña <Math tex={"\\wedge"} /> a todo <Math tex={"\\Lambda(V^*)"} /> de manera bilineal. Es decir, si <Math display tex={"\\alpha=\\alpha_0+\\alpha_1+\\cdots+\\alpha_n,\\qquad \\alpha_i\\in\\Lambda^i(V^*)"} />
y <Math display tex={"\\beta=\\beta_0+\\beta_1+\\cdots+\\beta_n,\\qquad \\beta_j\\in\\Lambda^j(V^*),"} />entonces se define <Math display tex={"\\alpha\\wedge\\beta:=\\sum_{i=0}^n\\sum_{j=0}^n\\alpha_i\\wedge\\beta_j,"} />donde <Math display tex={"t\\in\\Lambda^0(V^*),\\quad \\theta\\in\\Lambda^k(V^*)\\implies t\\wedge\\theta=t\\theta."} />
Por las propiedades anteriores, <Math tex={"(\\Lambda(V^*),\\wedge)"} /> es una algebra asociativa, no conmutativa y con unidad <Math tex={"1\\in\\Lambda^0(V^*)"} />, que tiene dimension

</BookBlock>
