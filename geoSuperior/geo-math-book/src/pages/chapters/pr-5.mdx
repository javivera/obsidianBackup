Entonces <Math display tex={"F_1(u)=a\\,dx+b\\,dy+c\\,dz."} /> Aplicamos <Math tex={"d"} />: <Math display tex={"dF_1(u)=d(a\\,dx+b\\,dy+c\\,dz)=da\\wedge dx+db\\wedge dy+dc\\wedge dz."} /> Como <Math display tex={"da=a_x\\,dx+a_y\\,dy+a_z\\,dz,"} /> se tiene <Math display tex={"da\\wedge dx=a_y\\,dy\\wedge dx+a_z\\,dz\\wedge dx=-a_y\\,dx\\wedge dy+a_z\\,dz\\wedge dx."} /> Como <Math display tex={"db=b_x\\,dx+b_y\\,dy+b_z\\,dz,"} /> se tiene <Math display tex={"db\\wedge dy=b_x\\,dx\\wedge dy+b_z\\,dz\\wedge dy=b_x\\,dx\\wedge dy-b_z\\,dy\\wedge dz."} /> Como <Math display tex={"dc=c_x\\,dx+c_y\\,dy+c_z\\,dz,"} /> se tiene <Math display tex={"dc\\wedge dz=c_x\\,dx\\wedge dz+c_y\\,dy\\wedge dz=-c_x\\,dz\\wedge dx+c_y\\,dy\\wedge dz."} /> Sumando, obtenemos <Math display tex={"dF_1(u)=(c_y-b_z)\\,dy\\wedge dz+(a_z-c_x)\\,dz\\wedge dx+(b_x-a_y)\\,dx\\wedge dy."} /> Pero <Math display tex={"\\operatorname{rot}(u)=\\left(c_y-b_z,a_z-c_x,b_x-a_y\\right)."} /> Por la definición de <Math tex={"F_2"} />, resulta <Math display tex={"F_2(\\operatorname{rot}u)=(c_y-b_z)\\,dy\\wedge dz+(a_z-c_x)\\,dz\\wedge dx+(b_x-a_y)\\,dx\\wedge dy."} /> Por lo tanto, <Math display tex={"dF_1(u)=F_2(\\operatorname{rot}u)."} />  
4. **Probamos la conmutatividad del tercer cuadrado**. Sea <Math tex={"u=(a,b,c)"} />. Entonces <Math display tex={"F_2(u)=a\\,dy\\wedge dz+b\\,dz\\wedge dx+c\\,dx\\wedge dy."} /> Aplicamos <Math tex={"d"} />: <Math display tex={"dF_2(u)=da\\wedge dy\\wedge dz+db\\wedge dz\\wedge dx+dc\\wedge dx\\wedge dy."} /> Ahora <Math display tex={"da\\wedge dy\\wedge dz=a_x\\,dx\\wedge dy\\wedge dz,"} /> porque los términos con <Math tex={"dy\\wedge dy"} /> y <Math tex={"dz\\wedge dz"} /> son cero. También <Math display tex={"db\\wedge dz\\wedge dx=b_y\\,dy\\wedge dz\\wedge dx=b_y\\,dx\\wedge dy\\wedge dz,"} /> y <Math display tex={"dc\\wedge dx\\wedge dy=c_z\\,dz\\wedge dx\\wedge dy=c_z\\,dx\\wedge dy\\wedge dz."} /> Por lo tanto, <Math display tex={"dF_2(u)=(a_x+b_y+c_z)\\,dx\\wedge dy\\wedge dz."} /> Pero <Math display tex={"\\operatorname{div}(u)=a_x+b_y+c_z."} /> Entonces, por la definición de <Math tex={"F_3"} />, <Math display tex={"F_3(\\operatorname{div}u)=(a_x+b_y+c_z)\\,dx\\wedge dy\\wedge dz."} /> Por lo tanto, <Math display tex={"dF_2(u)=F_3(\\operatorname{div}u)."} />  
5. De los pasos anteriores, el diagrama conmuta: <Math display tex={"F_1\\circ\\operatorname{grad}=d,"} /> <Math display tex={"F_2\\circ\\operatorname{rot}=d\\circ F_1,"} /> <Math display tex={"F_3\\circ\\operatorname{div}=d\\circ F_2."} />  
6. Deducimos que <Math tex={"\\operatorname{div}\\operatorname{rot}=0"} />. Sea <Math tex={"u\\in\\mathfrak X(U)"} />. Entonces <Math display tex={"F_3(\\operatorname{div}(\\operatorname{rot}u))=dF_2(\\operatorname{rot}u)=d(dF_1(u))=d^2F_1(u)=0."} /> Como <Math tex={"F_3"} /> es un isomorfismo, se sigue que <Math display tex={"\\operatorname{div}(\\operatorname{rot}u)=0."} />  
7. Deducimos que <Math tex={"\\operatorname{rot}\\operatorname{grad}=0"} />. Sea <Math tex={"f\\in C^\\infty(U)"} />. Entonces <Math display tex={"F_2(\\operatorname{rot}(\\operatorname{grad}f))=dF_1(\\operatorname{grad}f)=d(df)=d^2f=0."} /> Como <Math tex={"F_2"} /> es un isomorfismo, se sigue que <Math display tex={"\\operatorname{rot}(\\operatorname{grad}f)=0."} />
- (c)
1. Finalmente decidimos si <Math tex={"u(x,y,z)=(x,0,0)"} /> puede ser el rotor de algún campo vectorial en <Math tex={"\\mathbb R^3"} />. 
2. Si existiera <Math tex={"v\\in\\mathfrak X(\\mathbb R^3)"} /> tal que <Math display tex={"\\operatorname{rot}(v)=u,"} /> entonces por el paso anterior tendríamos <Math display tex={"\\operatorname{div}(u)=\\operatorname{div}(\\operatorname{rot}v)=0."} />
3. Pero para <Math tex={"u=(x,0,0)"} />, <Math display tex={"\\operatorname{div}(u)=\\frac{\\partial x}{\\partial x}+\\frac{\\partial 0}{\\partial y}+\\frac{\\partial 0}{\\partial z}=1."} />
4. Esto contradice que <Math tex={"\\operatorname{div}(u)=0"} />. Por lo tanto, <Math display tex={"u(x,y,z)=(x,0,0)"} /> no puede ser el rotor de ningún campo vectorial suave en <Math tex={"\\mathbb R^3"} />.
</Proof>
