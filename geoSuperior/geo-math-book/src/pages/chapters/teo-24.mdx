# Orientacion de espacios vectoriales

## Orientacion de espacios vectoriales

<BookBlock kind="definition" title="Orientacion de un espacio vectorial">
Sea <Math tex={"V"} /> un espacio vectorial real de dimension finita. Se define una relacion de equivalencia en el conjunto de bases ordenadas de <Math tex={"V"} /> como:

Si <Math tex={"\\mathcal B_1"} /> y <Math tex={"\\mathcal B_2"} /> son bases ordenadas, decimos que
<Math display tex={"\\mathcal B_1\\sim\\mathcal B_2"} />
si el determinante de la matriz de cambio de base de <Math tex={"\\mathcal B_1"} /> a <Math tex={"\\mathcal B_2"} /> es positivo.

Las clases de equivalencia se llaman orientaciones de <Math tex={"V"} />.
</BookBlock>

<BookBlock kind="exercise">
Verificar que la anterior relacion es una relacion de equivalencia en el conjunto de bases ordenadas.
<Proof title="Demostracion" open>
1.
</Proof>
</BookBlock>

<BookBlock kind="proposition">
La relacion de equivalencia en el conjunto de bases ordenadas de <Math tex={"V"} /> tiene solo dos clases de equivalencia.
<Proof title="Demostracion">
1. **Hay al menos dos clases:** Sea <Math tex={"\\mathcal B=\\{v_1,\\ldots,v_n\\}"} /> una base de <Math tex={"V"} />. Entonces <Math display tex={"\\widetilde{\\mathcal B}=\\{-v_1,v_2,\\ldots,v_n\\}"} />tambien es base de <Math tex={"V"} />, y la matriz de cambio de base tiene determinante <Math display tex={"\\det\\begin{pmatrix}-1& &0\\\\&\\ddots&\\\\0& &1\\end{pmatrix}=-1<0."} />
2. Por lo tanto <Math tex={"\\mathcal B"} /> y <Math tex={"\\widetilde{\\mathcal B}"} /> no estan en la misma clase.
3. **Hay exactamente dos:** Sean <Math tex={"\\mathcal B"} /> y <Math tex={"\\widehat{\\mathcal B}"} /> dos bases ordenadas que no estan en la misma clase. Sea <Math tex={"\\mathcal B'"} /> una tercera base ordenada. 
4. Si <Math tex={"\\mathcal B'\\sim\\mathcal B"} />, listo. Si no, entonces el determinante de la matriz de cambio de base de <Math tex={"\\mathcal B"} /> a <Math tex={"\\mathcal B'"} /> es negativo.
5. Como <Math tex={"\\mathcal B"} /> y <Math tex={"\\widehat{\\mathcal B}"} /> no estan en la misma clase, tambien <Math display tex={"\\det\\left(M_{\\mathcal B}^{\\widehat{\\mathcal B}}\\right)<0."} />
6. Sabemos que <Math display tex={"M_{\\mathcal B}^{\\mathcal B'}=M_{\\widehat{\\mathcal B}}^{\\mathcal B'}M_{\\mathcal B}^{\\widehat{\\mathcal B}},"} />y por tanto <Math display tex={"\\det\\left(M_{\\mathcal B}^{\\mathcal B'}\\right) =\\det\\left(M_{\\widehat{\\mathcal B}}^{\\mathcal B'}\\right)\\det\\left(M_{\\mathcal B}^{\\widehat{\\mathcal B}}\\right)."} />
7. Como los dos determinantes de los extremos tienen signo negativo, se sigue que <Math display tex={"\\det\\left(M_{\\widehat{\\mathcal B}}^{\\mathcal B'}\\right)>0,"} />y entonces <Math tex={"\\mathcal B'\\sim\\widehat{\\mathcal B}"} />.
</Proof>
</BookBlock>

<BookBlock kind="definition" title="Espacio vectorial orientado">
Un espacio vectorial orientado es un par <Math tex={"(V,[\\mathcal B])"} />, donde <Math tex={"V"} /> es un espacio vectorial real de dimension finita y <Math tex={"[\\mathcal B]"} /> es una clase de equivalencia de la relacion de orientacion en el conjunto de bases ordenadas de <Math tex={"V"} />.

Una base ordenada <Math tex={"\\mathcal B"} /> de <Math tex={"V"} /> se dice positivamente orientada si <Math tex={"\\mathcal B\\in[\\mathcal B]"} />.
</BookBlock>

<BookBlock kind="remark">
Si <Math tex={"V"} /> tiene dimension <Math tex={"n"} />, podemos usar una <Math tex={"n"} />-forma no nula para dar una orientacion a <Math tex={"V"} />.
</BookBlock>

<BookBlock kind="lemma">
Sea <Math tex={"\\omega\\in\\Lambda^n(V^*)"} /> y sea <Math tex={"\\mathcal B=\\{e_1,\\ldots,e_n\\}"} /> una base de <Math tex={"V"} />. Entonces, dados <Math tex={"v_1,\\ldots,v_n\\in V"} /> arbitrarios, se cumple que
<Math display tex={"\\omega(v_1,\\ldots,v_n)=\\det A\\ \\omega(e_1,\\ldots,e_n),"} />
donde <Math tex={"A"} /> es la matriz cuya columna <Math tex={"j"} /> son las coordenadas de <Math tex={"v_j"} /> en la base <Math tex={"\\mathcal B"} />.
<Proof title="Demostracion">
1. Sea <Math tex={"\\mathcal B^*=\\{e_1^*,\\ldots,e_n^*\\}"} /> la base dual de <Math tex={"V^*"} />. Sabemos que <Math display tex={"e_1^*\\wedge\\cdots\\wedge e_n^*"} />es base de <Math tex={"\\Lambda^n(V^*)"} />. 
2. Por lo tanto existe <Math tex={"\\lambda\\in\\mathbb R"} /> tal que <Math display tex={"\\omega=\\lambda e_1^*\\wedge\\cdots\\wedge e_n^*."} />
3. Evaluando en la base, <Math display tex={"\\omega(e_1,\\ldots,e_n)=\\lambda."} />
4. Por otra parte, si <Math tex={"A=(a_{ij})"} /> es la matriz de coordenadas de los <Math tex={"v_j"} />, entonces <Math display tex={"\\omega(v_1,\\ldots,v_n)=\\lambda\\det(a_{ij})=\\det A\\ \\omega(e_1,\\ldots,e_n)."} /> recordando que <Math tex={"e_{j}^{*}(v_{i})"} /> nos da la <Math tex={"j"} />-esima coordenadas de el vector <Math tex={"v_{i}"} /> escrito en la base <Math tex={"\\mathcal{B}"} />   
</Proof>
</BookBlock>

<BookBlock kind="proposition">
Sea <Math tex={"V"} /> un espacio vectorial real de dimension <Math tex={"n"} />. Cada elemento no nulo <Math tex={"\\omega\\in\\Lambda^n(V^*)"} /> determina una orientacion <Math tex={"\\mathcal O"} /> de <Math tex={"V"} /> de la siguiente manera:
<Math display tex={"\\mathcal O=\\{(E_1,\\ldots,E_n)\\text{ base ordenadas}:\\omega(E_1,\\ldots,E_n)>0\\}."} />
Dos <Math tex={"n"} />-tensores alternantes no nulos determinan la misma orientacion si y solo si uno es multiplo positivo del otro.
<Proof title="Demostracion">
1. Sea <Math tex={"\\mathcal B=\\{e_1,\\ldots,e_n\\}"} /> una base ordenada y sea <Math tex={"\\omega\\in\\Lambda^n(V^*)"} /> no nula. Vamos a ver que la clase de equivalencia de esta base está dada por las bases ordenadas <Math tex={"\\{v_1,\\ldots,v_n\\}"} /> tales que <Math tex={"\\omega(v_1,\\ldots,v_n)"} /> tiene el mismo signo que <Math tex={"\\omega(e_1,\\ldots,e_n)"} /> 
2. Supongamos tenemos otra base ordenada <Math tex={"\\{ v_{1},\\ldots,v_{n} \\}"} /> entonces: <Math display tex={"\\begin{align}\\{ v_{1},\\ldots v_{n} \\}\\in [\\{ e_{1},\\ldots e_{n} \\}]& \\iff \\det(M_{\\widetilde{B}}^{B} )>0\\\\& \\iff \\frac{\\omega(v_{1},\\ldots,v_{n})}{\\omega(e_{1},\\ldots,e_{n})}=\\det(M_{\\widetilde{\\mathcal B}}^{B} )>0\\\\&\\iff \\omega(v_{1},\\ldots,v_{n})\\ \\land \\ \\omega(e_{1},\\ldots,e_{n})\\ \\text{tienen el mismo signo}\\end{align}"} /> el primer paso por definicion el segundo por <PreviewLink href="/chapters/teo-24#543d91" label="Lema" title="Lema" /> 
3. Por lo tanto una orientacion de <Math tex={"V"} /> esta dada por las bases ordenadas <Math tex={"\\{ v_{1},\\ldots v_{n} \\}"} /> tales que <Math tex={"\\omega(v_{1},\\ldots,v_{n})"} /> tienen el mismo signo. 
4. Normalmente llamamos orientacion (denotada <Math tex={"\\mathcal{O}_{\\omega}"} />) a las bases tales que <Math tex={"\\omega(v_{1},\\ldots,v_{n})>0"} /> osea tienen el mismo signo y son positivas.
5. Si <Math tex={"\\widetilde{\\omega}"} /> es otra <Math tex={"n"} />-forma no nula en <Math tex={"\\Lambda^{*}(V^{*})"} />, claramente <Math display tex={"\\mathcal{O}_{\\omega}=\\mathcal{O}_{\\widetilde{\\omega}}\\iff \\widetilde{\\omega}=\\lambda\\omega \\  \\text{ con } \\ \\lambda>0"} />    
</Proof>
</BookBlock>

## Orientacion de variedades

<BookBlock kind="definition" title="Variedad orientable y atlas orientado">
Una variedad suave conexa <Math tex={"M"} /> de dimension <Math tex={"m"} /> se dice orientable si existe un atlas suave <Math tex={"\\mathcal A"} /> tal que para cualquier par de cartas suaves <Math display tex={"(U,\\varphi=(x_1,\\ldots,x_m)),\\qquad (V,\\psi=(y_1,\\ldots,y_m))"} />en <Math tex={"\\mathcal A"} />, con <Math tex={"U\\cap V\\ne\\varnothing"} />, se cumple <Math display tex={"\\det\\left(\\frac{\\partial y_j}{\\partial x_i}\\right)>0\\qquad \\text{sobre }U\\cap V."} />
Un atlas con esta propiedad se llama **atlas orientado**.
</BookBlock>

<BookBlock kind="remark">
Dicho **atlas orientado** induce una orientacion en cada <Math tex={"T_{p}M"} /> con <Math tex={"p\\in M"} /> dada por la clase de equivalencia de <Math display tex={"\\left\\{ \\frac{\\partial}{\\partial x_{1}}\\bigg|_{p},\\ldots, \\frac{\\partial}{\\partial x_{m}}\\bigg|_{p}\\right \\}"} /> para cualquier carta <Math tex={"(U,\\varphi=(x_{1},\\ldots,x_{m}))\\in \\mathcal{A}"} />   
Esto es por que notamos que como el **atlas orientado** tenemos que <Math display tex={"0<\\det\\left(\\frac{\\partial y_j}{\\partial x_i}\\right)_{ij}=\\det(J(\\psi\\circ\\varphi ^{-1}))\\circ\\varphi \\qquad\\text{sobre}\\quad U\\cap V"} />
En particular si la otra carta que tomamos <Math tex={"(V,\\psi=y_{1},\\ldots y_{m})\\in \\mathcal A"} /> cumple <Math tex={"p\\in V"} /> entonces por definicion de **atlas orientado** tenemos que   <Math display tex={"\\det \\big[ J(\\psi\\circ\\varphi ^{-1})(\\varphi(p))\\big]>0"} /> pero esta es la matriz de cambio de base entre <Math display tex={"\\left\\{\\frac{\\partial}{\\partial x_1}\\bigg|_p,\\ldots,\\frac{\\partial}{\\partial x_m}\\bigg|_p\\right\\}\\qquad\\text{y}\\qquad \\left\\{\\frac{\\partial}{\\partial y_1}\\bigg|_p,\\ldots,\\frac{\\partial}{\\partial y_m}\\bigg|_p\\right\\}."} /> con lo cual en el espacio vectorial de <Math tex={"T_{p}M"} /> estas bases pertenecen a la misma clase de equivalencia.
</BookBlock>

<BookBlock kind="example">
1. <Math tex={"\\mathbb R^n"} /> es orientable.
2. <Math tex={"S^n"} /> es orientable con <Math tex={"n\\geq 2"} /> 
</BookBlock>

<BookBlock kind="proposition">
En general, cualquier variedad que pueda cubrirse con dos cartas suaves tal que <Math tex={"U\\cap V"} /> sea conexo 
<Proof title="Demostracion">
1. Sea <Math tex={"M"} /> una variedad que puede cubrirse con dos cartas suaves <Math tex={"(U,\\varphi=(x^1,\\ldots,x^m))"} /> y <Math tex={"(V,\\psi=(y^1,\\ldots,y^m))"} /> tales que <Math tex={"U\\cap V"} /> sea conexo.
2. Tenemos la función <Math display tex={"f:U\\cap V\\to\\mathbb R \\qquad q\\mapsto\\det\\!\\left(\\frac{\\partial y^j}{\\partial x^i}(q)\\right)"} />  
3. Como <Math tex={"\\left(\\frac{\\partial y^j}{\\partial x^i}(q)\\right)"} /> es una matriz de cambio de base, se tiene <Math tex={"f(q)\\neq0"} /> para todo <Math tex={"q\\in U\\cap V"} />.  
4. Además, <Math tex={"f"} /> es continua. Como <Math tex={"U\\cap V"} /> es conexo, <Math tex={"f(U\\cap V)"} /> es un conjunto conexo de <Math tex={"\\mathbb R"} /> que no contiene al <Math tex={"0"} />. Por lo tanto, o bien <Math tex={"f>0"} /> en todo <Math tex={"U\\cap V"} />, o bien <Math tex={"f<0"} /> en todo <Math tex={"U\\cap V"} />.  
5. En el primer caso, <Math tex={"M"} /> es orientable por definición.  
6. En el segundo caso, cambiamos una de las cartas y definimos <Math tex={"\\tilde\\psi=(-y^1,y^2,\\ldots,y^m)"} />
7. Entonces <Math display tex={"\\det\\!\\left(\\frac{\\partial\\tilde y^j}{\\partial x^i}\\right)=-\\det\\!\\left(\\frac{\\partial y^j}{\\partial x^i}\\right)>0"} /> para todo punto de <Math tex={"U\\cap V"} />.  
8. Por consiguiente, el atlas <Math tex={"\\mathcal A=\\{(U,\\varphi),(V,\\tilde\\psi)\\}"} /> es una orientación de <Math tex={"M"} />.  
9. Luego, <Math tex={"M"} /> es orientable.
</Proof>

</BookBlock>

<BookBlock kind="definition" title="Carta positivamente/negativamente orientada">
Sea <Math tex={"(M, \\mathcal{A})"} /> una variedad orientada y sea <Math tex={"(U,\\varphi=(x_1,\\ldots,x_m))"} /> una carta suave arbitraria de <Math tex={"M"} />.
Se dice que <Math tex={"(U,\\varphi)"} /> esta positivamente orientada si la base ordenada <Math display tex={"\\left\\{\\frac{\\partial}{\\partial x_1}\\bigg|_p,\\ldots,\\frac{\\partial}{\\partial x_m}\\bigg|_p\\right\\}"} />tiene orientacion inducida por <Math tex={"\\mathcal A"} /> para todo <Math tex={"p\\in U"} />
Es decir para cada <Math tex={"p\\in U"} /> sucede que <Math display tex={"\\det\\left(\\frac{\\partial y_j}{\\partial x_i}\\bigg|_{p}\\right)>0"} />para cualquier carta <Math tex={"(V,\\psi=(y_{1},\\ldots y_{n})"} /> en <Math tex={"\\mathcal A"} /> tal que <Math tex={"p\\in U\\cap V\\neq 0"} /> 
Analogamente se define carta negativamente orientada.
</BookBlock>

<BookBlock kind="proposition">
Sea <Math tex={"(M,\\mathcal A)"} /> una variedad orientada y sea <Math tex={"(U,\\varphi=(x_1,\\ldots,x_m))"} /> una carta suave de <Math tex={"M"} /> con <Math tex={"U"} /> conexo. Entonces <Math tex={"(U,\\varphi)"} /> es positivamente orientada o negativamente orientada.
<Proof title="Demostracion">
1. Consideremos los subconjuntos de <Math tex={"U"} /> <Math display tex={"U_+=\\left\\{p\\in U:\\left\\{\\frac{\\partial}{\\partial x_1}\\bigg|_p,\\ldots,\\frac{\\partial}{\\partial x_m}\\bigg|_p\\right\\}\\text{ es positivamente orientada con respecto a } \\mathcal A\\right\\},"} /><Math display tex={"U_-=\\left\\{p\\in U:\\left\\{\\frac{\\partial}{\\partial x_1}\\bigg|_p,\\ldots,\\frac{\\partial}{\\partial x_m}\\bigg|_p\\right\\}\\text{ es negativamente orientada con respecto a }\\mathcal A\\right\\}."} /> notar que en estos conjuntos hablamos de orientacion como espacios vectoriales
2. Vale la pena recalcar que <Math tex={"U_{+}"} /> y <Math tex={"U_{-}"} /> están bien definidas pues <Math tex={"\\mathcal A"} /> define una orientación en cada <Math tex={"T_pM"} />, con <Math tex={"p\\in M"} />, que no depende de la carta que se elija en <Math tex={"\\mathcal A"} />.
3. Veamos que ambos conjuntos son abiertos de <Math tex={"U"} /> 
4. **<Math tex={"U_{+}"} /> es abierto de <Math tex={"M"} />**: Sea <Math tex={"p\\in U_+"} /> y sea <Math tex={"(V,\\psi=(y_1,\\ldots,y_n))\\in\\mathcal A"} /> una carta de <Math tex={"p"} />.
5. Luego <Math tex={"p\\in U\\cap V"} /> y por definicion de <Math tex={"U_{+}"} /> tenemos que <Math display tex={"\\det\\!\\left(\\frac{\\partial y_i}{\\partial x_j}(p)\\right)>0"} />
6. Pensemos en la función <Math display tex={"f:U\\cap V\\longrightarrow\\mathbb R,\\qquad q\\longmapsto \\det\\!\\left(\\frac{\\partial y_i}{\\partial x_j}(q)\\right)"} />
7. Como las funciones <Math display tex={"\\frac{\\partial y_i}{\\partial x_j}:U\\cap V\\to\\mathbb R"} /> son <Math tex={"C^\\infty"} />, en particular son continuas, tenemos que <Math tex={"f"} /> es continua.
8. Y dado que <Math tex={"f(p)>0"} />, entonces <Math tex={"f>0"} /> en un abierto <Math tex={"W"} /> de <Math tex={"p"} /> de <Math tex={"U\\cap V"} />, el cual también es abierto de <Math tex={"M"} />.
9. Esto quiere decir que para todo <Math tex={"q\\in W"} />, la base <Math display tex={"\\left\\{\\frac{\\partial}{\\partial x_1}\\bigg|_q,\\ldots,\\frac{\\partial}{\\partial x_n}\\bigg|_q\\right\\}"} /> está positivamente orientada.
10. Por lo tanto <Math tex={"p\\in W\\subseteq U_{+}"} /> con <Math tex={"W"} /> abierto. Luego <Math tex={"U_{+}"} /> es abierto.
11. Análogamente, <Math tex={"U_{-}"} /> es un abierto de <Math tex={"M"} />.
12. Como <Math tex={"U_{+}"} /> y <Math tex={"U_{-}"} /> son disjuntos, y <Math tex={"M"} /> es conexo, entonces <Math tex={"M=U_{+}"} /> o <Math tex={"M=U_{-}"} />, que es lo que queríamos probar.
</Proof>
</BookBlock>

<BookBlock kind="remark">
Si una carta <Math tex={"(U,\\varphi)"} /> no esta positivamente orientada, podemos cambiar una coordenada, por ejemplo
<Math display tex={"(U,\\widetilde\\varphi)=(-x_1,x_2,\\ldots,x_m),"} />
y obtener una carta positivamente orientada.
</BookBlock>

<BookBlock kind="proposition" title="Caracterizacion de orientabilidad">
Sean <Math tex={"M"} /> una variedad suave conexa de dimension <Math tex={"n"} />. Entonces las siguientes afirmaciones son equivalentes:

- (a) <Math tex={"M"} /> es orientable.
- (b) Existe una <Math tex={"n"} />-forma continua nunca nula sobre <Math tex={"M"} />.
- (c) Existe una <Math tex={"n"} />-forma suave nunca nula sobre <Math tex={"M"} />.
<Proof title="Demostracion">
- **<Math tex={"(c)\\Rightarrow(b)"} />** es inmediato.
- **<Math tex={"(b)\\Rightarrow(a)"} />**. 
1. Tenemos <Math tex={"\\omega"} /> una <Math tex={"n"} />-forma no nula, recordamos que un <Math tex={"n"} />-tensor alternante no nulo define una orientación (en espacios vectoriales) 
2. Usamos la continuidad de la <Math tex={"n"} />-forma <Math tex={"\\omega"} /> para definir un atlas de orientación. 
3. Arrancamos con <Math tex={"\\mathcal A=\\{(U_\\alpha,\\varphi_\\alpha=(x_1^\\alpha,\\ldots,x_n^\\alpha))\\}_{\\alpha\\in I}"} /> un atlas suave de <Math tex={"M"} />, donde podemos suponer que cada <Math tex={"U_\\alpha"} /> es un conjunto conexo.
4. Recordar que las componentes conexas en un espacio topológico localmente conexo por caminos son abiertas.
5. Para cada <Math tex={"(U_\\alpha,\\varphi_\\alpha)\\in\\mathcal A"} />, consideramos la función <Math display tex={"f_\\alpha:U_\\alpha\\to\\mathbb R\\qquad p\\mapsto \\omega_p\\!\\left(\\left.\\frac{\\partial}{\\partial x_1^\\alpha}\\right|_p,\\ldots,\\left.\\frac{\\partial}{\\partial x_n^\\alpha}\\right|_p\\right)"} />
6. Como <Math tex={"\\omega"} /> es nunca nula y continua, entonces <Math tex={"f_\\alpha"} /> es continua y nunca nula.
7. Como <Math tex={"U_\\alpha"} /> es conexo, se sigue que <Math tex={"f_\\alpha>0"} /> o bien <Math tex={"f_\\alpha<0"} /> en todo <Math tex={"U_\\alpha"} />.
8. Si <Math tex={"f_\\alpha<0"} />, construimos la nueva carta suave <Math tex={"(U_\\alpha,\\widetilde\\varphi_\\alpha=(-x_1^\\alpha,x_2^\\alpha,\\ldots,x_n^\\alpha))"} />.
9. Nuestro atlas de orientación es <Math display tex={"\\mathcal A_0=\\{(U_\\alpha,\\varphi_\\alpha)\\in\\mathcal A:f_\\alpha>0\\}\\cup\\{(U_\\alpha,\\widetilde\\varphi_\\alpha):(U_\\alpha,\\varphi_\\alpha)\\in\\mathcal A,\\ f_\\alpha<0\\}."} />
- **<Math tex={"\\mathcal A_0"} /> es un atlas suave de <Math tex={"M"} />**: Sus cartas son suavemente compatibles. Veamoslo:
	1. Si <Math tex={"(U_\\alpha,\\varphi_\\alpha),(U_\\beta,\\varphi_\\beta)"} /> son t.q. <Math tex={"f_\\alpha>0"} />, <Math tex={"f_\\beta>0"} /> y <Math tex={"U_\\alpha\\cap U_\\beta\\neq\\varnothing"} />, entonces son suavemente compatibles porque están en <Math tex={"\\mathcal A"} />. Y <Math tex={"\\mathcal A"} /> es atlas suave
	2. Si <Math tex={"(U_\\alpha,\\varphi_\\alpha)"} /> y <Math tex={"(U_\\beta,\\widetilde\\varphi_\\beta)"} /> donde <Math tex={"f_\\alpha>0"} />, <Math tex={"f_\\beta<0"} /> y <Math tex={"U_\\alpha\\cap U_\\beta\\neq\\varnothing"} />. Consideremos <Math display tex={"T:\\mathbb R^n\\to\\mathbb R^n,\\qquad (x^1,\\ldots,x^n)\\mapsto(-x^1,x^2,\\ldots,x^n),"} />la cual es una transf. lineal t.q. <Math tex={"T^2=\\operatorname{Id}_{\\mathbb R^n}"} /> y <Math display tex={"\\widetilde\\varphi_\\beta=T\\circ\\varphi_\\beta,"} /> así <Math display tex={"\\widetilde\\varphi_\\beta\\circ\\varphi_\\alpha^{-1}=T\\circ \\underbrace{\\varphi_\\beta\\circ\\varphi_\\alpha^{-1}}_{\\text{suave, pues }\\mathcal A\\text{ es atlas}}"} /> y <Math display tex={"\\varphi_\\alpha\\circ\\widetilde\\varphi_\\beta^{-1}=\\varphi_\\alpha\\circ(T\\circ\\varphi_\\beta)^{-1}=\\underbrace{\\varphi_\\alpha\\circ\\varphi_\\beta^{-1}}_{\\text{suave, pues }\\mathcal A\\text{ es atlas}}\\circ T^{-1},"} />
	3. Y finalmente si <Math tex={"(U_\\alpha,\\widetilde\\varphi_\\alpha)"} />, <Math tex={"(U_\\beta,\\widetilde\\varphi_\\beta)"} /> son t.q <Math tex={"f_{\\alpha }<0"} /> y <Math tex={"f_{\\beta}<0"} /> entonces son suavemente compatibles: <Math display tex={"\\widetilde\\varphi_\\beta\\circ\\widetilde\\varphi_\\alpha^{-1}=(T\\circ\\varphi_\\beta)\\circ(\\varphi_\\alpha^{-1}\\circ T^{-1})=T\\circ(\\varphi_\\beta\\circ\\varphi_\\alpha^{-1})\\circ T^{-1}"} />
- **Para todo <Math tex={"p\\in M"} />, las cartas de <Math tex={"\\mathcal A_0"} /> definen la misma orientación en <Math tex={"T_pM"} />:**
	1. Sean <Math tex={"(U,\\varphi)"} />, <Math tex={"(V,\\psi)\\in\\mathcal A_0"} /> t.q. <Math tex={"U\\cap V\\neq\\varnothing"} />. Tenemos tres casos
	- **1er Caso:**
		1. Primero tenemos <Math display tex={"(U,\\varphi)=(U_\\alpha,\\varphi_\\alpha),\\qquad (V,\\psi)=(U_\\beta,\\varphi_\\beta),\\qquad f_\\alpha>0,\\ f_\\beta>0."} />entonces <Math display tex={"0<f_\\alpha=\\omega\\!\\left(\\frac{\\partial}{\\partial x_\\alpha^1},\\ldots,\\frac{\\partial}{\\partial x_\\alpha^n}\\right)=\\det\\!\\left(\\frac{\\partial x_\\beta^j}{\\partial x_\\alpha^i}\\right)\\omega\\!\\left(\\frac{\\partial}{\\partial x_\\beta^1},\\ldots,\\frac{\\partial}{\\partial x_\\beta^n}\\right)=\\det\\!\\left(\\frac{\\partial x_\\beta^j}{\\partial x_\\alpha^i}\\right)f_\\beta."} />
		2. Luego <Math display tex={"\\det\\!\\left(\\frac{\\partial x_\\beta^j}{\\partial x_\\alpha^i}\\right)>0."} />	 
	- **2do caso:** 
		1. Si <Math tex={"(U,\\varphi)=(U_\\alpha,\\varphi_\\alpha)"} /> y <Math tex={"(V,\\psi)=(U_\\beta,\\widetilde\\varphi_\\beta)"} />, con <Math tex={"f_\\alpha>0"} /> y <Math tex={"f_\\beta<0"} />
		2. Entonces, repitiendo la misma cuenta de arriba, tenemos <Math display tex={"\\begin{align} 0<f_\\alpha & =\\omega\\!\\left(\\frac{\\partial}{\\partial x_\\alpha^1},\\ldots,\\frac{\\partial}{\\partial x_\\alpha^n}\\right)\\\\ &=\\det\\!\\left(\\frac{\\partial \\widetilde x_\\beta^j}{\\partial x_\\alpha^i}\\right)\\omega\\!\\left(\\frac{\\partial}{\\partial \\widetilde x_\\beta^1},\\ldots,\\frac{\\partial}{\\partial \\widetilde x_\\beta^n}\\right)\\\\&=\\det\\!\\left(\\frac{\\partial \\widetilde x_\\beta^j}{\\partial x_\\alpha^i}\\right)\\omega\\!\\left(-\\frac{\\partial}{\\partial x_\\beta^1},\\ldots,\\frac{\\partial}{\\partial x_\\beta^n}\\right)\\\\&=-\\det\\!\\left(\\frac{\\partial \\widetilde x_\\beta^j}{\\partial x_\\alpha^i}\\right)\\omega\\!\\left(\\frac{\\partial}{\\partial x_\\beta^1},\\ldots,\\frac{\\partial}{\\partial x_\\beta^n}\\right)\\\\&=-\\det\\!\\left(\\frac{\\partial \\widetilde x_\\beta^j}{\\partial x_\\alpha^i}\\right)f_{\\beta }\\end{align}"} />

## Esto no lo dio en clase

<BookBlock kind="theorem" title="Orientabilidad de hipersuperficies">
Sea <Math tex={"M"} /> una subvariedad de dimension <Math tex={"n"} /> en <Math tex={"\\mathbb R^{n+1}"} />. Probar que <Math tex={"M"} /> es orientable si y solo si <Math tex={"M"} /> admite un campo normal diferenciable nunca nulo; es decir, una funcion diferenciable
<Math display tex={"\\xi:M\\to\\mathbb R^{n+1}"} />
tal que <Math tex={"\\xi(p)\\perp T_pM"} /> para todo <Math tex={"p\\in M"} />.
<Proof title="Demostracion">
**<Math tex={"(\\Leftarrow)"} />** Supongamos que existe <Math tex={"\\xi:M\\to\\mathbb R^{n+1}"} /> suave y nunca nula tal que <Math tex={"\\xi(p)\\perp T_pM"} /> para todo <Math tex={"p\\in M"} />.

Sea <Math tex={"\\omega"} /> la forma de volumen estandar de <Math tex={"\\mathbb R^{n+1}"} />. Definimos una <Math tex={"n"} />-forma sobre <Math tex={"M"} /> por
<Math display tex={"\\eta_p(v_1,\\ldots,v_n)=\\omega_p(\\xi(p),v_1,\\ldots,v_n),\\qquad v_i\\in T_pM."} />
Esta forma es suave. Ademas no se anula: si <Math tex={"v_1,\\ldots,v_n"} /> es una base de <Math tex={"T_pM"} />, entonces
<Math display tex={"\\{\\xi(p),v_1,\\ldots,v_n\\}"} />
es base de <Math tex={"\\mathbb R^{n+1}"} />, luego
<Math display tex={"\\omega_p(\\xi(p),v_1,\\ldots,v_n)\\ne0."} />
Por la proposicion anterior, <Math tex={"M"} /> es orientable.

**<Math tex={"(\\Rightarrow)"} />** Supongamos que <Math tex={"M"} /> es orientable. Queremos construir <Math tex={"\\xi"} /> suave y nunca nulo perpendicular a <Math tex={"T_pM"} />.

Como <Math tex={"M"} /> es orientable, existe una <Math tex={"n"} />-forma suave nunca nula <Math tex={"\\eta"} /> sobre <Math tex={"M"} />. Localmente, si <Math tex={"(U,\\varphi=(x_1,\\ldots,x_n))"} /> es una carta, los vectores
<Math display tex={"\\frac{\\partial}{\\partial x_1}\\bigg|_p,\\ldots,\\frac{\\partial}{\\partial x_n}\\bigg|_p"} />
forman una base de <Math tex={"T_pM"} />. En <Math tex={"\\mathbb R^{n+1}"} /> existe exactamente una direccion normal a este subespacio. Elegimos el vector normal unitario <Math tex={"\\xi(p)"} /> de modo que
<Math display tex={"\\omega_p(\\xi(p),v_1,\\ldots,v_n)"} />
tenga el mismo signo que <Math tex={"\\eta_p(v_1,\\ldots,v_n)"} /> para toda base positiva <Math tex={"v_1,\\ldots,v_n"} /> de <Math tex={"T_pM"} />.

Usando coordenadas locales, esta eleccion se escribe suavemente por cofatores: si
<Math display tex={"d i_p\\left(\\frac{\\partial}{\\partial x_j}\\bigg|_p\\right)\n=\\sum_{k=1}^{n+1}a_{kj}(p)\\frac{\\partial}{\\partial y_k},"} />
entonces un vector normal se obtiene como el vector de menores de la matriz <Math tex={"(a_{kj})"} />. Al normalizar, obtenemos un campo suave porque el vector de menores no se anula.
</Proof>
</BookBlock>

<BookBlock kind="remark">
La orientabilidad de una hipersuperficie se puede pensar como la posibilidad de elegir de manera suave un lado positivo, es decir, un campo normal nunca nulo.
</BookBlock>

### Orientacion inducida en el borde

<BookBlock kind="remark">
La orientacion del borde se elige con la convencion "normal saliente primero".

Si <Math tex={"M"} /> es una variedad orientada con borde y <Math tex={"p\\in\\partial M"} />, una base ordenada
<Math display tex={"(v_1,\\ldots,v_{n-1})"} />
de <Math tex={"T_p(\\partial M)"} /> es positiva si
<Math display tex={"(\\nu_p,v_1,\\ldots,v_{n-1})"} />
es una base positiva de <Math tex={"T_pM"} />, donde <Math tex={"\\nu_p"} /> es un vector normal saliente.
</BookBlock>

<BookBlock kind="example">
En un intervalo <Math tex={"[a,b]"} />, la orientacion inducida del borde es
<Math display tex={"\\partial[a,b]=\\{b\\}-\\{a\\}."} />
El punto derecho tiene signo positivo y el punto izquierdo tiene signo negativo.
</BookBlock>
