- Prefiere ejemplos sencillos y naturales antes que contraejemplos más avanzados o poco obvios.
- G_n denotes the multiplicative group of n-th roots of unity; it is cyclic of order n and has φ(n) generators.
- For the current exercise, every homomorphism from G_n (the n-th roots of unity) to Z is trivial: if g generates G_n, then n·φ(g)=0 in the torsion-free group Z, so φ(g)=0.
- A homomorphism from a cyclic group is completely determined by the image of a generator.
- For Hom(Z,G_n), the image of the generator 1 can be any element of G_n; hence there are n homomorphisms, one for each choice of φ(1).
- For a homomorphism from a cyclic group, the image of a finite-order generator must have order dividing the generator's order; if the generator has infinite order, its image is unrestricted by order.
- For arbitrary (not necessarily cyclic) groups, assigning generator images whose orders divide the corresponding source orders is not sufficient to define a homomorphism; all relations among the generators must also be preserved.
- For Hom(Z,Q), since Z is generated by 1 and Q is infinite, each choice q∈Q defines exactly one homomorphism φ_q(m)=mq; therefore Hom(Z,Q) is infinite.
- For Hom(Q,Z), because Q is divisible under addition, any homomorphism φ:Q->Z satisfies φ(1)=n·φ(1/n) for all n>0, forcing φ to be identically 0 (Hom(Q,Z) = {0}).
- For the current Hom exercise, both Hom(Z_2×Z_2,Z_4) and Hom(Z_4,Z_2×Z_2) contain exactly four homomorphisms.
