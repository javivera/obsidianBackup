# Memory
- The vault 'estructurasAlgebraicas' is an Obsidian math knowledge base on algebraic structures containing definitions, theorems, propositions, and proofs.
- The 'Practicos' folder contains course exercise sheets stored as PDF sources ('EA - PrN.pdf') with matching Markdown notes ('EA - PrN.md') that transcribe the statements.
- Solved exercises are written as full proofs into the matching 'EA - PrN.md' note, following that file's callout and LaTeX style.
